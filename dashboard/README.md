## How this page is made

`make dashboard` runs `tools/make_paper_dashboard.py`, which reads each study's `paper-log/decisions/*.json`, `shadow.csv` (Study 003: its §11.5 `summary.csv`), `executions/*.json`, `runs.jsonl` and `stops.jsonl` as committed, compounds the shadow lines' net returns (or reads the book values Study 004 writes) into one path per series, and draws it with `qune_research/style.py`. The SHA-256 of every input file and the generation time are in `manifest.json`. The page is regenerated by the work loop after each record; a run that finds nothing new changes only the time stamp. The forward records' own rules (no record before the close, never overwritten, misses logged as misses) are in each study's `paper-log/README.md`.
