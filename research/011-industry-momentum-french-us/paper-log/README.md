# Study 011 shadow forward record (PREREGISTRATION.md §11)

Shadow only: the industry portfolios are not approved instruments, so there is no paper order and no paper sleeve.

- `cohorts.csv`: one row per forward holding month t and trial (M1, M1a, M1b), appended by `python -m src.forward011 record --month YYYY-MM` from **the first release of the Kenneth French Data Library that contains month t − 1** (the code refuses any other release and any month recorded out of order), never replaced. Each row carries the cohort ranked at the end of t − 1 (winners and losers in rank order, boundary ties), every eligible industry's formation return at full precision, the release, the two zips' SHA-256, the manifest's hash and download times, and the record time. The commit time in git is the evidence of when the row existed; rows committed after the first release that contains month t will be labelled "late" at scoring and still scored. The five earlier cohorts held in t are the earlier rows or, for the first forward months, the history run's (`results/history/cohorts.json`).
- Part 2 (fetch of later releases, interim figures with no t-statistic, one-time scoring after 60 holding months from 2026-09 to 2031-08 with a vintage row) is not yet written; it comes with its own separate code review before any forward month can be scored. Over 60 months the record can detect only a Sharpe of d of about 1.27 at 80% power, so its verdict will be worded as a low-power check.

First record: 2026-09 from release 202608 (the history snapshot, downloaded 2026-10-26 15:31:23Z), recorded 2026-10-26 before release 202609 was available to the desk (Study 010's fetch at 17:15:43Z found the library still on 202608). It equals the history run's 2026-08 cohorts for all three trials. Code decisions: PREREGISTRATION.md §16 (2026-10-26); review: CODE_REVIEW.md, second part.
