# Vendor-derived series removed from the current tree (2026-10-30)

Decided by Qune on 2026-10-30 (reduces exposure, reversible from git history; the owner's decision on the question put on 2026-10-28 was still open). The 26 files below held monthly or daily return series and per-ETF signal tables computed from Tiingo and Alpaca daily bars. Both vendors' terms restrict republishing their market data and say nothing about derived series (`intraday_source_check.md`, check 1), so the series are no longer distributed from this repository. The files are in every commit up to `b1a6650` (history is not rewritten; `git show b1a6650:<path>` prints any of them). Every published statistic computed from them (`metrics_*.csv`, `summary.json`, the charts, the tear-sheets, the review tables) stays as published.

Each study's `reproduce.sh` regenerates a file under the reader's own vendor access (the modes below; the run-once guards refuse while the results folder exists, so regenerate in a copy of the study folder) and the SHA-256 here, which is also recorded for the chart and tear-sheet inputs in `charts/manifest.json` and `tearsheets/manifest.json`, shows whether the regenerated file is the one the results were computed from.

Not removed: Study 004's `results/oos/signal_*.csv` (eight files of the same kind). Its forward code (`src/forward.py`) reads the last row of `signal_s12_10assets.csv` and `signal_vol_10assets.csv` as the starting state of the forward record, whose first entry is due after 21:15 UTC on 2026-10-30. They are removed once that code reads a frozen starting-state file instead, after a review; a desk improvement is queued for it. Also kept: every file computed from FRED series (the synthetic legs of Studies 006–008, the 001/002 validation tables, the desk view's rate series), the Kenneth French tables of Studies 010 and 011 (cited; their own question is unchanged) and the vendor comparison aggregates in `results/checks/`.
